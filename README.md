# Documenti casa — demo

Versione dimostrativa di un'app per archiviare e tenere sotto controllo i documenti di casa: bollette, condominio, assicurazioni, mutuo, lavori e ristrutturazioni, garanzie e multe.

- **Dati interamente fittizi.** Importi, date e titoli sono inventati.
- Nessun account, nessuna sincronizzazione: ciò che inserisci resta solo in questo browser (pulsante "Ripristina" per ripartire).
- PWA installabile, funziona offline. Codice senza build: HTML, CSS e JavaScript.

La versione reale sincronizza i dati su un repository GitHub privato e legge le bollette dalla posta: queste parti sono disattivate nella demo.
